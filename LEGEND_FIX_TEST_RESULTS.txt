ISSUE DESCRIPTION
═══════════════════════════════════════════════════════════════════════════════

PROBLEM:
  Legend was not displayed when using the group.by feature in the linePlot
  module, even though the legend should show the different group values.

ROOT CAUSE:
  The linePlot_module_server.R had a hardcoded:
    show.legend = FALSE
  This was passed to the linePlot function regardless of user input.
