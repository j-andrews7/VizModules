# vizModules (development version)

## New features

* Added marginal plot functionality to `dittoViz_scatterPlot` module
  - Supports density, histogram, rug, and combined density+rug marginal plots
  - Marginal plots respect grouping and color mappings from the main scatter plot
  - Rugplots are dodged by group for better visibility
  - Controls for opacity, histogram bins, rug height, and relative marginal plot size
  - Automatically disabled when faceting is used
  - New "Marginals" tab in the UI with intuitive controls
